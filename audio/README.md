# Ljud

`tonpar/*.mp3` och de HSK-ord som studion hämtar från GitHub kommer från
[audio-cmn](https://github.com/hugolpz/audio-cmn) (Hugo Lopez, PLIDAM, INALCO).
Talare för HSK-orden: Yue Tan, licens CC BY-SA (via Shtooka-projektet).
Filerna är oförändrade, 64 kbit/s mp3.

`tonpar.json` listar ord per tonpar (skriven ton för första och andra stavelsen, 5 = neutral).
Pinyin och engelsk betydelse från CC-CEDICT (CC BY-SA). `hsk-index.json` listar alla ord som har inspelning.

`stcmds/*.mp3` och `stcmds.json`: 1 081 vardagsmeningar ur Free ST Chinese Mandarin Corpus
(ST-CMDS-20170001_1, Surfingtech, [OpenSLR 38](https://openslr.org/38)), licens CC BY-NC-ND 4.0.
Endast formatbyte från wav till mp3; inget innehåll är redigerat. Pinyin genererat med pypinyin (kan innehålla enstaka fel).
